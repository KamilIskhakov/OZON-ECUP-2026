# Порядок воспроизведения: от `train.parquet` до двух финальных файлов

В репозитории 79 скриптов — это журнал двухнедельного поиска, и большинство
из них относится к отвергнутым гипотезам (см. [EXPERIMENTS.md](EXPERIMENTS.md)).
Здесь перечислено только то, что реально участвует в финале, в порядке
выполнения.

## 0. Быстрая проверка без пересчёта

Направления сохранены в `artifacts/neural/*_a408.npz`, поэтому финальные CSV
проверяются мгновенно и без данных:

```bash
python scripts/verify_finals.py
```

Все четыре шага сборки сходятся с точностью $5.6\cdot10^{-17}$.

## 1. Данные и панель

```bash
# data_start/train.parquet и sample_submit.csv — из комплекта соревнования
python -c "from ecup import load_panel; load_panel(rebuild=True)"
```

Строит кеш `data_work/train_compact.parquet`: дата заменяется на целочисленный
день `d`, типы ужимаются. Около 160 МБ, две минуты.

## 2. Табличный бэкбон

```bash
python scripts/fact_ensemble.py      # 6 LightGBM + 12 CatBoost, веса 0.4/0.6
python scripts/alt_lgb_prod.py       # боевые LGB на якоре 408
```

Даёт OOF-прогнозы `artifacts/neural/oofpm_a*.npz` на всех якорях и боевой
прогноз на 408. Около полутора часов на 11 ядрах.

## 3. Направления поверх бэкбона

| шаг | скрипт | выход | время |
| :--- | :--- | :--- | ---: |
| Gap-GRU (исходный) | `train_gapgru.py --production` | `dz_prod_a408.npz` | 40 мин GPU |
| блок бескэповой истории | `longmoney_prod.py` | `longmoney_prod_a408.npz` | 30 мин |
| годовой фильтр | считается в `strong_base.py:annual()` | — | секунды |
| Gap-GRU на трёх поздних якорях | `train_gapgru.py --folds 318,348,378:: --anchor-weights 0.5,0.7,1.0` | `gruprod_dir_a408.npz` | 40 мин GPU |
| признаки BG/NBD | `btyd_prod.py` | `btyd_prod_a408.npz` | 40 мин |

Токены для последовательностных моделей строятся заранее:

```bash
python scripts/build_tokens.py --max-len 384 --max-history 420 --out artifacts/neural/tokens384
```

Обрезка истории здесь критична: значение по умолчанию `--max-history 300`
отсекало дальнюю историю и стоило нам целого блока признаков.

## 4. Сборка финала

Каждое направление добавляется в $z$-шкале со своим коэффициентом,
восстановленным по параболе из замеров публичной части:

```
v32 = ...                             (линейная оболочка отправленных решений)
v34 = v32 + 0.0943 * gruprod_orth
v36 = v34 + 0.2860 * btyd_orth
v37 = v36 + hull2d по осям [v34, v27]         <- финальный слот 1
hedge = v23 + (1/3)(v37 - v23)                <- финальный слот 2
```

Скрипты сборки: `make_v36.py` и блоки в `verify_finals.py`, который
одновременно служит и проверкой.

## Что НЕ участвует в финале

Отрицательные ветки, оставленные в репозитории ради полноты журнала:
`train_tcn.py`, `build_dense.py`, `pretrain_tcn.py` (плотная дневная решётка),
`funnel.py` (воронковые параметры), `cohort_audit.py` (когортный аудит
остатка), `conditional_geometry.py` (условные коэффициенты), `btyd2.py`,
`btyd_abl.py` (расширения BG/NBD), `orth_target.py`, `build_strong.py`
(ортогональная цель и retargeting).

Все их результаты и причины отклонения — в [EXPERIMENTS.md](EXPERIMENTS.md).

## Требования

GPU нужна только для последовательностных моделей (Gap-GRU). Табличная часть
и BG/NBD считаются на CPU. Полный пересчёт с нуля — около шести часов, из них
полтора часа GPU.
